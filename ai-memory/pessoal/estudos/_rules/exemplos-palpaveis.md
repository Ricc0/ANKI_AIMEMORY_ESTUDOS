# Regra: exemplos palpáveis, nunca fraude, auditoria ou CGU

Pedido do usuário (2026-11-14, com irritação): parar de usar exemplos de fraude, notas fiscais, auditoria e CGU. Ele **não presta a CGU** (o alvo é a ANPD; ver [[missao-concurso]]) e esses exemplos o confundem.

## Usar
- **Teste de COVID / exame médico** para a matriz de confusão: o resultado já se chama positivo ou negativo, então VP/FP/FN/VN ficam intuitivos.
- **Filtro de spam** (precision), **triagem de câncer** (recall), **preço de apartamento** (regressão, R²), tempo de entrega, recomendação de filmes.
- Contexto da **ANPD/proteção de dados** quando encaixar: vazamento de dados pessoais, consentimento, decisão automatizada.

## Estado
